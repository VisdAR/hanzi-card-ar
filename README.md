# 汉字图卡 AR

无需安装 App 的手机网页游戏：扫描实体图卡角落的二维码，二维码应指向
`https://visdar.github.io/hanzi-card-ar/?play=1`。手机会直接打开游戏并请求相机权限；
随后对准图卡，用拇指和食指捏住构字部件，让部件在镜头画面里相遇，直接组成汉字。

发布后的可打印入口为 [`print-card.html`](https://visdar.github.io/hanzi-card-ar/print-card.html)：二维码位于识别图卡外侧，因此不会破坏图像定位素材。

普通手机相机不能把一张任意图片直接变成正在运行的游戏；二维码是 iPhone、iPad、Android 都能识别的通用启动入口。可打印图卡把二维码设计为“汉字绿洲印”：它看起来是图卡的一部分，但仍保留扫码必需的对比度和留白。二维码打开的是网页，玩家不需要手动搜索或输入网址。

## 本地测试

```sh
python3 -m http.server 4174 --directory dist
```

正式使用必须从 HTTPS 地址打开，浏览器才会允许相机。

## 实现与当前边界

网页使用 MindAR 识别启动图、Three.js 渲染字形、MediaPipe 在后置相机画面中寻找手指捏合。图卡入口现在只显示构字部件，不再加载早期的粗糙几何场景；图卡离开镜头后组字会暂停。

识别图卡后可进入 360° 绿洲。`dist/world360.html` 使用原创 2:1 全景作为远景，分别放置带透明背景的近中景素材，并以少量数字方块从下向上显现。素材提高了色彩饱和度并降低遮挡实景的透明度。近景目前是面向镜头的图层，尚非可绕到背后的完整 3D 模型；更新的素材 URL 有版本号，避免手机继续显示旧藤架。

每境有三个组字任务，进入时随机排列；第二境包含两个回顾字。字形保留在场景坐标中，对准并靠近字形后可以捏合抓取，亦可点按钮抓取。抓住的字形接近另一枚后按空间距离融合。组成一个字会在它旁边显示拼音、构字解说和本境剩余字数，再由玩家点击进入下一字。法语和英语可切换，中文同时保留；外语安全提示和操作提示更加醒目。

支持 WebXR immersive-ar 和 hit-test 的设备可以尝试定位脚下水平面：页面排除明显的墙面、桌面高度，并等连续多帧稳定后把场景和字形固定在检测到的平面上；可依据手机的真实位置限制抓取距离。若会话报告 `NotSupportedError`，地面按钮会隐藏，并在入口中说明设备无法使用此功能。其余设备只用普通相机与手机转动传感器提供原地 360° 环视；它们的字形仅固定在虚拟环视坐标中，**不具备地面定位或障碍物检测**。即使有 WebXR 平面定位，也无法可靠发现楼梯、悬崖、边缘或所有障碍；游戏始终要求玩家站在平坦空旷处、原地转身并用眼睛确认真实环境。

在 Mac 上预览静态场景可运行上面的本地服务器，再打开 `http://127.0.0.1:4174/world360.html?preview=1`。该预览入口只在 localhost 有效，不打开相机。

Unity/Vuforia 工程可用于原生 Android/iOS 应用；本仓库交付的是免安装网页，因此浏览器端使用上述网页技术。WebXR 模式主要使用手机准星及轻触抓取；普通相机环视模式尝试启用 MediaPipe 手势识别，手势不可用时仍可轻触抓取。
